# YOLOv8 摄像头实时目标检测

## 项目功能
调用电脑摄像头实时读取画面，使用 YOLO 预训练模型检测画面物品，显示检测框、类别和置信度。

## 环境说明
- 操作系统：Ubuntu
- Python 版本：3.9
- 主要依赖：ultralytics, opencv-python

## 如何运行
1. 创建并激活虚拟环境：
   conda create -n vision python=3.9
   conda activate vision
2. 安装依赖：
   pip install -r requirements.txt
3. 运行程序：
   python main.
